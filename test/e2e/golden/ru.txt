=== dialog-category-rules
Правила категорий
Правила
По одному на строку: слово = Категория. Регистр не важен, срабатывает первое совпадение. Для знакомых магазинов сначала берётся их последняя категория. Ставьте «Оплата платежа» для платежей, которые уже есть на вкладке «Платежи», чтобы не считать их дважды.
Заодно разнести операции этого месяца без категории
